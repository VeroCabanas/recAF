# Elección de licencia

## Licencia seleccionada: MIT

`recAF` se publica bajo licencia MIT porque la autora desea permitir la reutilización más amplia posible. La licencia autoriza, sin coste, el uso, copia, modificación, integración, publicación, distribución, sublicencia y venta de copias. Su condición principal es conservar el aviso de copyright y el texto de la licencia en las copias o partes sustanciales. Además, establece expresamente que el software se proporciona sin garantías.

MIT permite que otras personas creen y distribuyan versiones modificadas, incluso en productos comerciales y sin obligación de publicar sus cambios. Si la finalidad fuese obligar a que las versiones derivadas mantuvieran abierto su código, una licencia de *copyleft* como GPL sería más adecuada; esa no es la opción seleccionada para `recAF`.

La licencia MIT está aprobada por la Open Source Initiative y utiliza el identificador SPDX `MIT`.

## Reconocimiento por GitHub

GitHub incluye `MIT` entre sus palabras clave de licencia y utiliza Licensee para comparar el archivo `LICENSE` con textos conocidos. El repositorio contiene en su raíz el texto canónico de MIT, con la única personalización prevista: `Copyright (c) 2025 Verónica Cabanas Sánchez`.

Tras subir el repositorio se comprobará visualmente que GitHub muestra `MIT license` en la portada. Esa comprobación en línea solo puede realizarse cuando el repositorio exista.

## Relación con GGIR

`recAF` no incorpora ni redistribuye el código fuente de GGIR; lo declara como dependencia. GGIR 3.2-6 está licenciado bajo Apache License 2.0. La licencia MIT de `recAF` es adecuada para este uso y el README reconoce explícitamente la dependencia y sus autores.
